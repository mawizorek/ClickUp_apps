Signal Documentation System

14-table normalized schema for unified production signal documentation across audio, lighting, video, and network.

Schema (14 tables)

  1. SIGNAL_TYPES (vocabulary)
  2. FIXTURE_TYPES (vocabulary)
  3. TYPE_INTERFACES (expected ports per fixture type)
  4. VENUES
  5. POSITIONS (named locations, including people)
  6. INFRASTRUCTURE (tie lines, circuits, home runs)
  7. NETWORKS (VLANs, subnets)
  8. SHOWS (title, season, venue, designers)
  9. ENDPOINTS (abstract parent for units + CPs)
  10. UNITS (physical things placed for a show)
  11. CONTROL_POINTS (virtual entities inside devices)
  12. NETWORK_INTERFACES (IP assignments per device)
  13. CONNECTIONS (signal paths between endpoints)
  14. ASSIGNMENTS (bus routing + group membership)

Data Backup

Data persists in localStorage. Use Export JSON to download a full backup. Import via the browser console: SignalDB.importAll(JSON.parse(data))
