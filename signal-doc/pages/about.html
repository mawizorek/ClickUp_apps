Signal Doc

One schema for every signal in the building: audio, lighting, video, network, power. Replaces the Lightwright + Minotaur + spreadsheet stack with a single traceable model.

How it's built

Fourteen normalized tables. Fixture types define their expected ports, units are the instances, control points are the virtual things inside a device (input channels, mix buses, multiview slots), connections are physical or network patches, and assignments cover bus sends and group membership in one table.

Traces are computed live by walking connections and assignments from a unit's endpoints. Nothing is cached, so a trace is always current.

Your data

Everything is stored in this browser only. Export a JSON backup before closing a session; that's the file Import restores from. Excel export gives one sheet per table for reading and sharing (Excel may warn about the file format on open; click Yes).

Reset wipes local data and reloads the Big Love F26 sample.
