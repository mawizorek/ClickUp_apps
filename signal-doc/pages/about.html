Signal Doc

One schema for every signal in the building: audio, lighting, video, network, power. Replaces the Lightwright + Minotaur + spreadsheet stack with a single traceable model.

How it's built

Fourteen normalized tables. Fixture types define their expected ports, units are the instances, control points are the virtual things inside a device (input channels, mix buses, multiview slots), connections are physical or network patches, and assignments cover bus sends and group membership in one table.

Traces are computed live by walking connections and assignments. Nothing is cached, so a trace is always current.

Your data

Every edit saves in this browser first, then syncs to the Signal Doc server (Cloudflare D1) when you're signed in. Offline edits queue and send when you're back. If someone saved the same row before you, you keep their version and get a heads-up.

Backups: nightly server snapshots, 30-day point-in-time restore, and JSON / Excel export on the Units screen.

Roles

Admin edits everything, manages users, locks shows. Department head edits rows whose signal type is in their department, in the shows they're granted. Guest viewer reads the shows shared with them, without networks or IPs. Permissions are editable on the Access screen.
