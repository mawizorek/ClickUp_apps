Add a print to the catalog. Name is the only thing required — everything else can come later.

Stored as — — permanent identity. The display name can change later; this cannot.

Category is size, edition type is how many exist. A mini print can be any of the three — Brooklyn Ginkgo is a mini and unique.

Retail is dollars. Not cents.

Saving writes the artwork, and the database creates its edition in the same transaction. Nothing else has to be running for this to work.
