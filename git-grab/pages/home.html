Grab a folder

Paste a link to any folder on GitHub. Get back a .zip of that folder and everything inside it.

Pick a folder

Open the folder on GitHub and copy the address bar. A /tree/ link, a /blob/ link to a single file, or a permalink with a long commit hash all work. Public repositories only \u2014 private repos need a token, which comes later.

Nothing downloads until you have seen the file list. The count on that list is the point: a download is only correct when it matches the number of files in the zip and the number GitHub reports, and anything that cannot be packed (submodules and symlinks have no real file content to fetch) is named rather than quietly dropped.

Every request goes to github.com and nowhere else, enforced by a hostname allowlist in gh.js rather than promised in a README. Files are zipped in your browser; nothing is uploaded anywhere.
