Appearance

Every code is generated in this tab. The URL you type is encoded into the module pattern itself, so the code resolves to that exact address forever — there is no shortener, no redirect service and no account behind it. Nothing is uploaded and nothing is stored.

The flip side: a static code cannot be repointed. If the destination URL ever changes, every printed copy of that code is dead. For anything you expect to outlive its link, encode a redirect you control rather than the final address.

Error correction is a real tradeoff, not a quality setting. Higher levels survive more scuffing and ink loss but pack more modules into the same square, which makes small prints harder to read. Q is the default for that reason.
