## 3. 🔑 THE HONEST FINDING ABOUT THE OTHER COLUMN

**There is almost no "doesn't know." There is UNDECIDED and there is UNASKED, and neither one is ignorance.**

- ⚠️ **Unknown to BOTH of us is a third thing** and it gets said plainly (§5).

### The live UNASKED list — ask it, never assert it, and 🚫 never hedge an answer on it

1. 🔴 **His VW update level and macOS version.** `Vectorworks ▸ About Vectorworks`. **First question on any performance answer** — Update 2.1 names his exact two symptoms as fixed bugs (`VB-216958`, `VB-216838`) and `VB-216202` is a Tahoe issue. **Configuration work on a defective build measures the defect** (C4).
