## 3. ❓ OPEN ABOUT HIS SETUP — ASK. NEVER ASSERT, NEVER HEDGE ON IT.

🔴 **These are facts about his rig that no session has been told.** A blank here is **silence, not a limitation** (gate §2–§3), and a whole recommendation may never be qualified on one. Each carries the ONE question that closes it.

1. 🔴 **His VW update level, and his macOS version.** `Vectorworks ▸ About Vectorworks`. **This is the first question on any performance answer**, because VW2026 Update 2.1 names his exact two symptoms as fixed bugs (`VB-216958` file open takes forever · `VB-216838` crash when updating reference) and `VB-216202` is a Tahoe performance issue. **Configuration work on a defective build measures the defect** (C4).
2. **Whether `Update class definitions` is on, per reference.** ⚠️ **Not a knowledge gap — a UI-exposure gap.** The switch is absent from Select Viewport Source and lives only in `Edit` on the References tab, so if he created his references through Create Viewport he has plausibly never been shown it. Its default state is undocumented. **The tool hid it; he did not miss it.**
3. **Whether his MASTERS are DLVP or layer import.** Decides tier-two circular exposure. His own tier is settled; theirs is not.
4. **His real References-tab ROW count.** `Existing Reference` lets several viewports ride one row, and open cost is the ROWS — so his good-faith "8" may be an overcount. One glance, his to make.
5. **Whether `Log time in program` is on** (Session pane, off by default). It times file opens, which is the only thing that turns *"forever"* into a number.
6. **Which orientation language this building speaks** — upstage/downstage vs compass vs clock face. Venue-local by practice, and it belongs in the legend. A venue fact, so also A1: it is not a standard.
7. **The uniform design-layer scale value**, recorded nowhere.
8. **`classes/walls/`** — what those four files were meant to be.
