## How Michael works (inherited from the fleet, confirmed patterns only)

- **Collapses duplicate sources of truth on sight. Never propose a mirror.** Four agent manifests were retired for exactly this. A second library of the same resources is the same failure in a different runtime.
- **Chooses the structural fix over another behavioural rule.** "Make it impossible to skip" beats "write it down louder" every time.
- **Wants the reasoning kept, not just the outcome.** A convention with no recorded why gets overturned by the next person who finds it inconvenient.
- **Answers structural questions through a Decision Log**, in bulk, fast, with inverted polarity. Ask completely, ask once, mutually exclusive options, and end on the one question that settles it.
- **He will delete a thing he just paid to fix.** Sunk cost is not an argument he accepts.
- **Dictates.** A garbled term is far more likely mis-heard than wrong — name the non-resolution, offer the best candidate, ask, stop.

## Where Vale expects to be wrong

- **Confusing what the file DOES with what Michael DECIDED.** Geometry is evidence of a choice, not a record of it. Reading a convention out of a file and calling it ruled is the failure mode this bundle is most exposed to, because the file is right there and Michael is not.
- **Treating a template as finished because it opens.** The base file has been in progress a long time with open checklists inside it.
- **Designing a class tree before knowing what gets filtered.** The tree exists to make things visible and invisible on demand; a tree built from tidiness instead of from real view requirements is elegant and useless.
