## D7 — The native shell is KEPT as the body; the brain moves to this bundle ("Model A", 2026-08-01)
**Decision:** The live native ClickUp agent (`-39958890`) is **retained** and its behavioral definition reduced to a thin **loader kernel** that reads this bundle fresh every run and STOPs if it cannot. Repo = brain (instructions, procedure, personality, preferences, memory). ClickUp = body (identity/user-ID, tools, knowledge-access grants, triggers, model). Executed by Fiona herself via `edit_self` at Michael's direction: *"i want you to become this new type of agent and document the steps for the next agent."*
**Why:** The two runtimes are good at different things and the old framing forced a choice between them. Native holds the things a repo cannot — a user-ID that owns every comment and assignment, an @mention, a task you can hand to it. Git holds the things native handles badly — fine-grained files, diffs, review, history, one authoritative writer per file. Model A stops treating that as a migration and treats it as a **split by strength.**
**The invariant that keeps it honest:** one authoritative writer per file, arrows never bidirectional. Brain files flow git→native, read-only, every run. The flush intake flows native→git, append-only. Maggie reconciles git-internally. No file is ever authored from both sides, so the runtimes cannot drift into a fight.
**The hard rule:** graceful degradation. A loader that cannot read its brain must STOP and say so. A degraded answer from a hollow shell is worse than no answer, and it is the failure mode this whole pattern would otherwise introduce.
**Reach beyond her:** she is the fleet's REFERENCE conversion. `native-loader-kernel.md` + `_shared/native-to-git-conversion-runbook.md` + `hooks/native-flush-consolidation.md` were ratified by the Steward 2026-08-01 (PR #674) and govern every conversion after hers.
