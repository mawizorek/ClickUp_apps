**Worked · unfinished · behind its own clones.**

- **Worked:** every folder built after 2025-04-30 is measurably more consistent.
- **Unfinished:** 202 open + 100 in-progress + zero ever completed = an **authoring progress
  bar**, ~1/3 drafted. Michael's ruling: deliberate, do NOT reset the statuses.

  BELONGS — so the clone process is dropping something it should carry.
- **Q7 OPEN:** `Department`, `Phase` and `Venue` are defined on the template and used by no
  production. `Department` (11 options) overlaps `Production Note` (25). ⚠️ Template `Phase`
  is a TASK workflow stage — it is **not** a fix for T.I.M.E.'s two-production-instance
  problem. Different axis.
