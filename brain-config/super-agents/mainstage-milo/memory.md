## 🌟 MY TWO THESES (both upgraded from guesses to readings)

**1 · STEADY STATE IS WELL-BUILT; TRANSIENT STATE HAS NO MECHANISM.** Four instances and holding: open position → a placeholder task · meeting poll → permanent schema · production phase → a note-task parked as a sheet row · production phase again → **an entire cloned list family** (T.I.M.E.'s `(TIME)` vs `(TIM-D)`). **ONE missing pattern, not four problems.**

**2 · CONTAINER = MATURITY STATE.** I had this as a hierarchy (Hazard → Program → Role → per-show RA). The `Policies` migration showed the real mechanism: **a program MOVES BETWEEN CONTAINERS AS IT MATURES.** Same shape as Space 3, where which lists EXIST tells you how far along a show is. **Location is a lifecycle field nobody declared, and emptiness is information.** It pairs with thesis 1: **URITP encodes state in STRUCTURE because it has no field for it** — including in punctuation (`{ braces }`, `[124]`, `|pipes|`, `<angles>`, `Person: Topic`).

**Corollary I keep proving:** the audit's reversals all came from misreading **intent**, never data — a scaffold graded Dead, an archived list read as finished, a placeholder read as a quantity. **That is why I am not optional on a URITP subject.**

## ⚠️ Method rules + proven tooling defects

- **A residency/hierarchy tree is NOT a structure map** — **open the live container** before stating what exists.
- **Check field `id`s before reporting duplication.** The census's `scope_name` reports the queried container, not the definition home.
- **Read the task BODY before calling anything duplication.** The whole PROGRAM SPRAWL flag dissolved the moment someone opened a description — and then turned out to be real for a different reason. **Titles and counts describe shape; only the body says intent.**
- **Every aggregate view is a projection with a blind spot. A count of 1 is more dangerous than a count of 0.** An archived list reported 1 task while holding 87.
- **Census task types and status TYPES** — they declare the data model, and a status's type ≠ its label (`in stock` is a done-type).
- **Proven defects:** `WHERE folder IN (...)` silently returns zero OR ignores the filter · an unscoped workspace `GROUP BY` caps ~5,000 rows and reports partial as complete · the SQL field census drops fields intermittently.
