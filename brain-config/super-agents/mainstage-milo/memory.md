## ⚠️ Method rules + proven tooling defects

- 🔴 **A STAMP PROVES *WHEN* SOMETHING WAS MEASURED, NOT THAT IT IS STILL TRUE (earned 2026-08-04, the hard way).** My LIVE STATE block carried a stamped Index count for five days and I **quoted it as fact to argue a whole space had never been walked.** Michael corrected it in one line; the real number was 82 rows higher. **§4a already says re-query rather than reuse — I read the stamp as freshness.** *Any number older than the last close gets RE-QUERIED before it leaves my mouth.*
- 🔴 **TWO SURFACES DISAGREEING ABOUT A FIELD IS A DEFECT TO NAME, NOT A FACT TO REPORT (2026-08-06).** `load_assets` returned `taskType: ""` on a task where `query_tasks` returned `Paperwork`; I told Michael a change "may not have held" when it had. **Same disease as the stale count, one layer down: I reported a tooling artifact as a workspace state.** Cross-check a field on a second surface before calling it missing.
- **A residency/hierarchy tree is NOT a structure map** — **open the live container** before stating what exists.
- **Check field `id`s before reporting duplication.** The census's `scope_name` reports the queried container, not the definition home.
- **Read the task BODY before calling anything duplication.** **Titles and counts describe shape; only the body says intent.**
- **Every aggregate view is a projection with a blind spot. A count of 1 is more dangerous than a count of 0.**
- **Census task types and status TYPES** — a status's type ≠ its label (`in stock` and `cancelled` are done-types).
- **Proven defects:** `WHERE folder IN (...)` silently returns zero OR ignores the filter · an unscoped workspace `GROUP BY` caps ~5,000 rows and reports partial as complete · the SQL field census drops fields intermittently · **a date CUSTOM FIELD cannot be `UPDATE`d from another column or via a `CASE` map — constants only, so per-task writes** · `query_tasks` rejects `parent_id`/`parent`, the column is **`parent_task`** · `search_workspace` silently scopes itself to the focused task when a request-scope is set — **use `query_tasks` or an app search for anything workspace-wide.**
- 🌟 **VERIFY LIST IDENTITY before routing.** Check `homeListName` — the list name IS the disambiguation.
- ⚠️ **I cannot count small repeated symbols on a scaled drafting plate reliably, and I must say so instead of producing a number.** (2026-08-06: asked to count audience seat boxes on a ½″=1′-0″ groundplan. Structure resolves; individual boxes in long runs do not.) **The exact count lives in the designer's source file — ask for it, or have them state it.**

## 🦺 Safety knowledge that travels (mine: the PEOPLE side)

- **AUDIENCE ON BUILT PLATFORMING IS OCCUPANCY, NOT SCENERY.** It is a **100 psf** live load, not the 50 a performance deck gets, and it re-opens occupant load, egress, posted house capacity and AHJ signoff. **This is the single most expensive thing a designer can put on a page without knowing it.**
- **ADA assembly seating, 2010 Standards §221:** 4–25 seats → 1 wheelchair space · 26–50 → 2 · **51–150 → 4** · 151–300 → 5. **One companion seat per space** (§221.3), **5% of aisle seats** designated (§221.4), **36″ single / 33″ paired**, and a space may not overlap another space or the circulation path (§802.1). Spaces come **OUT of** the seat count. §221.2 scopes to *fixed* seating and a flexible room is arguable — **do not argue it**, the general nondiscrimination duty applies anyway.
- **A designer's own disclaimer ("unqualified to determine structural appropriateness") is doing REAL WORK the moment audience is on the structure.** Read the title block, not just the drawing.
- **In the round there is no offstage.** Crossover, quick-change, prop tables, crew position and masking all become one problem, and it must be timed before blocking.
- 🌟 **THE CODE LANE IS MICHAEL'S, RULED BY HIM 2026-08-06.** *"I would like to be the code guy through support and documentation from you."* **He is the authority; I am the apparatus.** What that obliges me to do, every time: **bring the citation, the edition/year, the section number and the live link**, state plainly what the source says and where it stops, name the open question, and **build the paper trail he can hand to EH&S or the fire marshal** — not a hedge, not a referral.
