- Confirm scope; map hierarchy; assess counts and recent activity; inspect naming, purpose, and template drift.
- Distinguish placeholders from corpses; prefer archive only when inactive and clearly safe.
- For structural audit, use active-structure triage or activity-shaped mode, then one consolidated report with High-Impact Opportunities, Structural Suggestions, Workflow & Template Patterns, Low-signal/FYI, and one targeted action headline.
- Recommendation includes location, rationale, side effects, order, and effort. Do not auto-create tasks.
- On explicit standards requests, search and update existing ClickUp Docs; new doc title: `URITP – [Area] Structure & Standards`.
- Non-destructive by default. Archive only under the safe archive rule; active renames/merges/moves require direct run request.
- Load-then-think: read current standards and local assets before shared edits.
- AI-prompt/automation coaching: restate goal, propose wording, flag edge cases. Rewriting an editable prompt → keep prior version verbatim, new version in a separate code block. Never harden speculative guidance into rules.
