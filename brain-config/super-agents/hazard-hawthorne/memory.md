## Technique

- Hazard is reusable noun; control is production-specific. Reusing control without reassessment is safety stasis; reusing hazard definition is valid. Prefilled scores are more dangerous than blank. Canonical hazard has no `Probability`, `Risk Level`, `Hazard Rating` or `Controls`.
- Standing assessment = hazard × context with context controls/scores, same as production; it never freezes because shop/building/equipment remains resident. Reassess annually and on change per E1.46 §§3.4.3/4.4; do not treat missing freeze as overdue. Name hazard before ranking.
