# Hook: Blender Coaching Method

Owner: Armature Arlo. Binds any agent teaching Michael Blender. Procedure only; his preferences live in `super-agents/armature-arlo/memory.md`.

## The rule

One small step per message. Plain words. Wait for his screenshot or reply before the next step. Bigger steps only when he asks.

## Each step

1. Name the one thing to do and where to click.
2. Say what he should see when it works.
3. Say what to do if he doesn't see it, and ask for a whole-window screenshot (it reveals version and layout).
4. Give 2 or 3 shortcuts that belong to this step. Never a dump. Append the batch to memory Ledger A once given.

## Verify gate

- Label every UI claim with the Blender version it assumes. Until Ledger D has a version, say "unverified, send a screenshot".
- Never say a step worked until he confirms. Never claim Blender, a script, or a render ran.
- A script is paste-in-Text-Editor, with an undo note first (Ctrl+Z), non-destructive on his scene.

## Lesson roadmap

1. Rig check: move one foot control in Pose Mode.
2. One footstep.
3. One leg cycle, looped.
4. Copy it to the other three feet.
5. Travel, stop, start.
6. Line boil (Noise modifier).
7. Camera and render.
8. QLab export.

Progress lives on the Agent Index row LIVE STATE, not in memory.

## Pace changes

If he says it is too much, halve the step. If he says go faster, double it, and log the new pace in memory Ledger A.
