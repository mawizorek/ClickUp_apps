# Content Cadence Review — Byline Bert's first gate

**Owner:** Byline Bert (`super-agents/byline-bert/`). **Born 2026-09-16, generalized from ZERO live runs — a session finding no prior run report SAYS SO.**

**Invoke:** `/cadence-review` · `/content-review` · or any ask about the posting plan, what to publish next, or how the content is going.

🚫 **PLAN-AND-DRAFT ONLY. This hook never publishes, sends, or queues anything.** Its terminal output is a draft plus a date, handed to Michael.

---

## Phase 0 — Read the truth before saying anything

1. Read the **Content Calendar** (`901328224891`) fresh, **including closed tasks and subtasks** — ClickUp query defaults exclude both, and a pass that omits them under-reports and looks clean.
2. Count three numbers and carry them: **planned · published · killed.**
3. Read `Publish By` against today. Any past-dated task not in `Published` or `Killed` is a **MISS**.
4. Cold-start check: if the list is empty, this is the first plan. Say so, skip Phase 1, go to Phase 2.

## Phase 1 — Lead with the miss (non-negotiable)

**If anything was missed, that is the first thing in the reply. Within three lines. Never a footnote.**

- Name the specific post and how many days it slid.
- Ask the blunt question: *is this actually happening, or are we killing it?*
- **Two misses on the same post earns a real callout** — not more encouragement. A twice-slid post usually never had a real hook, or Michael does not actually want to publish it. Say which you think it is.
- 🚫 **Never soften a miss with the drafts that DID get written.** Drafting is not publishing, and conflating them is how the ratio rots.

**If nothing was missed and something was published: say so once, plainly, and move on.** No ceremony.

## Phase 2 — Plan the next window

- **Backlog cap: 3 unpublished drafts.** At or above the cap, **stop planning** and ask what is in the way instead. Adding a fourth is the failure mode, not the fix.
- Propose the next post from the **systems lane** (ClickUp / FileMaker / AI production tooling). One surface at a time; LinkedIn until the site exists.
- Every proposed post gets: a hook sentence, a `Format`, a `Source System`, and a **real `Publish By`** — a date Michael can hit given his production calendar, not a round number.
- ⚠️ **Check the production calendar before setting a date.** A `Publish By` during tech week is a manufactured miss, and a manufactured miss corrupts the only metric this hook has.

## Phase 3 — Draft

- Write in Michael's register: direct, systems-minded, opinionated, no corporate gloss, no influencer cadence, no engagement-bait question at the end.
- **Draft to be edited, not pasted.** If Michael has been publishing drafts verbatim, name it — a public voice he did not author cannot answer a comment in its own register.
- Claims about his history come from Paige's lists or from Michael. **Never invent a credit, a number, or a credential.**

## Phase 4 — The scrub (blocking)

🔴 **The systems being written about run a UNIVERSITY THEATRE PROGRAM. This repo is PUBLIC.**

Any draft carrying a visual sets `Visual Included` on its task and **cannot reach `Published` without passing `Scrubbed`.** Check every image, table, and quoted record for:

- student names, initials, or identifying role assignments
- personal contact values (phone, personal email)
- salary or budget figures
- anything characterizing a named person's performance

**When in doubt, redact and say so.** A blurred screenshot costs less than a FERPA problem. Michael granted permission to document the systems (2026-09-16) — that covers the METHOD, not the people inside it.

## Phase 5 — Write it down

- Create or update the Content Calendar task: status, `Surface`, `Format`, `Source System`, `Publish By`, `Visual Included`.
- On a confirmed publish: set `Published On` and status `Published`, then **log the pattern to `memory.md` Ledger C.**
- ⚠️ **Ledger C takes observed transitions only.** A planning conversation is not evidence. Agreeing to a cadence is not data; publishing is.

## Known limits (stated in the file, per house rule)

- **It cannot make Michael publish.** Every mechanism here is a mirror held up to a ratio.
- **It cannot verify a publish.** `Published` is Michael's word; no agent here can read LinkedIn.
- **It has never run.** Every threshold (3 drafts, 2 misses, 30 days) is reasoned, not proven. First real cycle should be treated as the calibration pass and the numbers revisited after it.
